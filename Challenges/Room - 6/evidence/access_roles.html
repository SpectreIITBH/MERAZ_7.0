📋 Role Description (from database schema)
"Continuity delegate role for the AETHER CORE system. Provides read-only access to all operational data, enabling the continuity system to maintain a complete snapshot of festival operations for reconstruction after a network outage. This role provides read access to all tables including the certificate trust store, which maps service identities, trusted certificates, and inter-service authentication tokens. The risk is accepted because the continuity service operates on an isolated network segment (AETHER relay cluster). — Rhea D'Souza, 2024-03-15"
⚠ Security Review Note — Filed 2024-04-02
"Reviewed nexus-continuity-delegate role. The role grants read access to the certificate trust store, which contains inter-service trust relationships. If the AETHER relay cluster is compromised, the trust store contents could be used to impersonate any NEXUS service. Recommend: restrict access to a filtered view that excludes authentication tokens. Status: ACKNOWLEDGED — deferred to post-festival security hardening phase. — Security review by Ila Sen"

⚠ Key observation: The admin role cannot read the certificate_trust_store table. Only the nexus-continuity-delegate role can. This means the AETHER continuity system has more access to trust relationships than the festival's own administrators. This is by design — and it is the design that made the breach possible.
